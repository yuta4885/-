# 社員スキルマップ ツール

自動車補修用部品の物流倉庫で、従業員のスキル・経歴を見える化するためのツールです。
「この人はどこの職場でどんな仕事をしてきて、今何ができるのか」を一目で把握できるようにし、
**人員配置・異動判断・育成計画・多能工化の推進**に役立てることを目的としています。
**人事評価や処遇決定のためのものではありません。**

Excelブックを「入力・保管の場所」、Pythonスクリプトを「集計・出力の道具」として使います。
Windowsパソコン上でローカルに完結し、インターネットなど外部への通信は一切行いません。

---

## 1. 必要なもの

- Windows パソコン
- **Microsoft Excel 365 または Excel 2021以降**（「個人詳細」シートがXLOOKUP・FILTER関数を使うため。
  古いExcel（2019以前）では「個人詳細」シートが `#NAME?` エラーになります）
- Python 3.9以降（[python.org](https://www.python.org/) からインストールできます。インストール時に「Add Python to PATH」にチェックを入れてください）

Pythonが入っていれば、他の専門知識は不要です。

---

## 2. フォルダ構成

```
社員スキルマップ/
├── README.md          ← このファイル
├── 実行.bat            ← ダブルクリックで実行
├── requirements.txt    ← 必要なライブラリの一覧
├── main.py             ← 実行の起点
├── src/                ← 処理本体（機能ごとにファイルを分割）
│   ├── config.py            … シート項目・作業項目・選択肢などの設定値
│   ├── calculations.py      … 年齢・勤続年数などの自動計算
│   ├── skill_review.py      … 品質不具合によるスキル見直しの反映ロジック
│   ├── sample_data.py       … サンプルデータ10人分の生成
│   ├── workbook_init.py     … 入力用シートの雛形作成
│   ├── data_reader.py       … 既存ブックの入力内容の読み込み
│   ├── effective_sheet.py   … 実効スキル・品質集計を書き出す隠しシートの生成
│   ├── list_sheet.py        … 「一覧表」シートの生成
│   ├── gap_check.py         … 属人化リスク（穴チェック）の集計
│   ├── extract.py           … 「抽出結果」シートの生成
│   └── individual_sheet.py  … 「個人詳細」シートの生成
├── vba/
│   └── 全員印刷マクロ.txt   … 個人詳細シートを全員分まとめて印刷／PDF化するVBAマクロ
└── output/
    └── 社員スキルマップ.xlsx  ← 生成されるExcelブック（このフォルダ内にのみ保存されます）
```

## 3. 使い方

### 初回実行（サンプルデータで動作確認）

1. `実行.bat` をダブルクリックします。
2. 自動的に必要なライブラリがインストールされ、`output/社員スキルマップ.xlsx` が
   架空の氏名10人分のサンプルデータ入りで新規作成されます。
3. `output/社員スキルマップ.xlsx` をExcelで開いて内容を確認してください。

### 実際のデータを入力する

1. `社員スキルマップ.xlsx` を開き、次の入力用シートに実データを入力・編集します（サンプルデータは消して構いません）。
   - 設定／社員マスタ／所属歴／免許・資格／社外教育／社内教育／品質不具合歴／スキル習熟度
2. 入力が終わったら、Excelを**保存して閉じ**、もう一度 `実行.bat` をダブルクリックします。
3. 入力内容をもとに「一覧表」「抽出結果」「個人詳細」が自動で最新化されます。

※ `実行.bat`（`main.py`）は、`output/社員スキルマップ.xlsx` が無ければ新規作成、
　すでにあれば入力内容から自動シートを再生成する、という一つの動きをします。
　コマンドを覚える必要はありません。**入力内容を変えたら実行し直す**、これだけです。

### コマンドで実行する場合

```
python main.py
```

## 4. シートの説明

### 入力用シート（現場管理者が編集する）

| シート名 | 内容 |
|---|---|
| 設定 | ①作業項目の一覧（自由に追加・削除可） ②等級別（G1〜G4）の目標スキルレベル表（GAP分析用、自由に編集可） |
| 社員マスタ | 社員1人1行の基本情報。年齢・勤続年数は自動計算されます |
| 所属歴 | 社員1人につき複数行。過去の配属・担当業務の履歴。在籍期間は自動計算されます |
| 免許・資格 | 保有資格と有効期限、実務での使用状況。有効期限は赤＝期限切れ／オレンジ＝3か月以内／黄＝6か月以内で色分けされます |
| 社外教育 | 社外の講習・研修の受講歴 |
| 社内教育 | 新人教育・安全教育などの社内教育の受講状況。「未受講」の行は赤で強調されます |
| 品質不具合歴 | 育成・再発防止のための記録です。**個人を責めるためのものではありません**。「見直し対象スキル項目」を設定すると、再認定日まで該当スキルの評価が一時的に引き下げられます（下記参照） |
| スキル習熟度 | 社員×作業項目で0〜5の習熟度を入力するマトリクス |

主要な項目（部署・班・等級・担当業務・役割・原因区分など）にはドロップダウンを設定済みです。
入力の表記ゆれ（「2班」と「第2班」など）を防げます。

**スキル習熟度の6段階**

| レベル | 意味 |
|---|---|
| 0 | 未経験 |
| 1 | 教育を受ければできる |
| 2 | 指示を受ければ一人でできる |
| 3 | 通常作業を一人で完結できる |
| 4 | 異常・イレギュラーにも対応できる |
| 5 | 人に教えられる |

作業項目を「設定」シートで追加した場合は、**「スキル習熟度」シートにも同じ見出しの列を追加**してから
習熟度を入力してください（自動で列は追加されません。実行時に追加漏れがあれば注意メッセージが表示されます）。

### スキルレベルの一時的な見直し（品質不具合との連動）

「品質不具合歴」シートで、不具合を起こした社員の行に「見直し対象スキル項目」「見直し後レベル」を入力すると、
「再認定日」を過ぎるまでの間、そのスキルは一覧表・抽出結果・個人詳細のすべてで「見直し後レベル」を
実際のレベル（実効レベル）として扱います。再教育などが完了して認定し直したら、再認定日を入力（または
過去の日付に更新）すれば、自動的に元のスキル習熟度シートの値に戻ります。

※この判定は**スクリプトを最後に実行した時点**のものです。再認定日を過ぎたのに一覧表の表示が
変わらない場合は、`実行.bat` を実行し直してください。

### 自動生成シート（編集しないでください。実行するたびに上書きされます）

| シート名 | 内容 |
|---|---|
| 一覧表 | 多能工化率のサマリー、全員×主要作業項目の習熟度マトリクス（色分け表示）、社員ごとの対応可能工程数（Lv3+）、人員配置の穴チェック（属人化リスク警告）を掲載 |
| 抽出結果 | あらかじめ用意した6つの条件で該当者を自動抽出（下記参照） |
| 個人詳細 | 社員番号をプルダウンで選ぶと、その人のデータが自動表示される1枚のシート（旧・社員ごとのシートを統合） |
| _有効スキル(自動計算) | 個人詳細シートが参照するための内部データ（非表示シート、直接見る必要はありません） |

**抽出結果の6パターン**

1. 海外出荷 Lv4以上（実効レベル基準）
2. 新人教育ができる人（Lv5・実効レベル基準）
3. フォークリフト保有かつ使用中
4. 安全教育 未受講者
5. 資格の有効期限が6か月以内（期限切れ含む）
6. スキルレベル見直し中の人（品質不具合による一時的な引き下げ）

### 個人詳細シートの使い方

1. 右上のプルダウン（社員番号）で見たい社員を選ぶと、基本情報・所属歴・資格・教育歴・
   スキル習熟度×目標GAP・品質不具合歴などが自動で表示されます。
2. スキル習熟度は、データバー（色の長さ）で一目で分かるようにしています
   （レーダーチャートの代わりに、どのExcelでも確実に表示できるセルベースの表現を採用）。
3. GAP列は「実効レベルー等級別目標レベル（設定シートで編集可）」を表示し、マイナスは赤、
   0以上は緑で表示されます。⚠マークは品質不具合による見直し中を示します。
4. 印刷プレビューを確認のうえ通常どおり印刷してください。A4縦1枚に収まるよう自動でページ設定
   （用紙サイズ・拡大縮小・印刷範囲）がされています。
5. 所属歴・資格・教育歴・品質不具合歴は、それぞれ最大件数（6〜9件）まで自動表示されます。
   それを超える件数がある社員では、超えた分は表示されません（列幅を超える文字列も見切れる場合が
   あります。詳しくはセルをクリックして数式バーでご確認いただくか、列幅を広げてください）。

## 5. 一覧表の新機能

- **多能工化率**：全員×全工程のうち、Lv3以上（一人前）の割合をシート上部に表示します。
- **対応可能工程数(Lv3+)**：一覧表の右端に、社員ごとにLv3以上の作業項目数を表示します。
- **穴チェック（属人化リスク）**：作業項目ごとにLv3以上が1人以下の場合、警告表示します。

## 6. 全員分をまとめて印刷する（初回のみ設定が必要）

「個人詳細」シートは1枚のシートをプルダウンで切り替える方式のため、全員分を一括印刷するには
Excelのマクロ（VBA）が必要です。openpyxl（本ツールがExcelブックを作るのに使っている部品）は
マクロを直接組み込めないため、**一度だけ、手動でマクロを設定**してください（5分程度）。

1. `output/社員スキルマップ.xlsx` を開き、`名前を付けて保存` で **Excelマクロ有効ブック（.xlsm）** として保存し直します。
2. `Alt + F11` を押してVBAエディターを開きます。
3. メニューの `挿入` → `標準モジュール` を選び、新しいモジュールを作成します。
4. `vba/全員印刷マクロ.txt` の中身を全部コピーして、モジュールに貼り付けます。
5. VBAエディターを閉じ、`表示` タブ → `マクロ` → `マクロの表示` から実行できます。
   - `個人詳細_全員PDF出力`：全員分をPDFに書き出します（`output/個人シートPDF/` フォルダに保存、推奨）
   - `個人詳細_全員印刷`：全員分をプリンターに直接印刷します
6. よく使う場合は、`挿入` → `フォーム` → `ボタン`（開発タブが必要）でシート上にボタンを配置し、
   マクロを割り当てると、ワンクリックで実行できるようになります（開発タブは
   `ファイル → オプション → リボンのユーザー設定` で有効にできます）。

※ .xlsm化した後にPythonスクリプトを再実行すると、再び `.xlsx` が新規作成されます。
　マクロを引き継ぎたい場合は、スクリプト実行後に改めて `.xlsm` として保存し直してください。

## 7. 注意事項

- 生成されるExcelブックには個人情報が含まれます。`output` フォルダの外にコピーしたり、
  メールやクラウドストレージで送付したりする際は取り扱いに十分ご注意ください。
- 本ツールはインターネットなど外部への通信を一切行いません。すべての処理はお使いのパソコン内で完結します。
- 「一覧表」「抽出結果」「個人詳細」「_有効スキル(自動計算)」の各シートは自動生成です。直接編集しても、
  次回実行時に上書きされます。内容を直すときは、元になっている入力用シート（社員マスタなど）を
  修正してから再実行してください。
- 品質不具合歴シートは、育成・再発防止を目的とした記録です。個人の評価や処遇判断には使用しないでください。
- 「年齢」「勤続年数」「在籍期間」「更新要否」の列はExcelの数式が入っており、ファイルを開くたびに
  自動で最新の日付を基準に再計算されます。直接上書き入力しないでください。

## 8. うまく動かないとき

- `実行.bat` をダブルクリックしても何も起きない／エラーが出る
  → Pythonがインストールされていない可能性があります。コマンドプロンプトで `python --version` を実行し、
  　バージョンが表示されるか確認してください。
- 「個人詳細」シートが `#NAME?` と表示される
  → お使いのExcelがXLOOKUP・FILTER関数に対応していません（Excel 2019以前など）。
  　Microsoft 365またはExcel 2021以降が必要です。
- 「個人詳細」シートの一部が `#SPILL!` と表示される
  → その社員の所属歴・資格・教育歴・品質不具合歴の件数が、表示できる最大件数
  　（6〜9件）を超えています。古い記録を整理するか、表示件数を増やしたい場合は
  　`src/individual_sheet.py` の `budget_rows` の値を大きくしてから再実行してください。
- 文字化けする
  → Excel側の文字コード設定ではなく、本ツールが生成する `.xlsx` はExcelの標準形式なので通常は発生しません。
  　文字化けする場合は、開いているExcelのバージョンをご確認ください。
- 「スキル習熟度シートに列が見当たりません」という注意が出る
  → 「設定」シートに追加した作業項目が「スキル習熟度」シートにまだ反映されていません。
  　スキル習熟度シートに同じ見出しの列を手動で追加してください。
